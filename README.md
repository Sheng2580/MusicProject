# 弦外

一个在电脑浏览器里运行的吉他练习小应用：在独立曲库中管理和选择歌曲，再进入以琴弦为主体的全屏弹奏画面，用鼠标左右扫弦，跟随节拍和和弦练习。音频处理、分析、伴奏合成和曲库存储都在本地浏览器完成，不使用云端音频分析或 GPT 服务；自动匹配封面时仅向公开曲库查询歌曲标题和歌手。

## 启动

需要 Node.js 20.19 或更高版本，以及 pnpm 11.19。首次运行时，在项目目录安装依赖并启动开发服务器：

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的本地地址（通常为 <http://127.0.0.1:5173>）。结束后在该终端按 `Control + C` 停止服务。

macOS 也可以在依赖安装完成后，双击项目根目录的 **启动弦外.command**。启动器会优先选择系统命令路径中的 Node.js，也兼容 Tuanjie Cowork 安装在当前用户目录内的 Node.js，然后在固定端口启动 Vite：

<http://127.0.0.1:5173>

启动器不会自动安装依赖或下载软件。如果 5173 端口已被占用，它会报错并停止，不会切换到其他端口。ChatGPT 应用附带的 Node.js 有原生模块加载限制，启动器会跳过它。

常用开发命令：

```sh
pnpm dev       # 启动开发服务器
pnpm test      # 运行自动化测试
pnpm build     # 类型检查并生成生产构建
pnpm preview   # 本地预览生产构建
```

## 开始弹奏

- 玩家只需在曲库上传 MP3，应用会在浏览器内自动生成逐音旋律、节拍与和弦，然后进入全屏弹奏画面；不需要寻找或上传琴谱。弹奏时边缘控制会自动隐去，留下琴弦和逐音提示；将鼠标移到画面上、下边缘可重新呼出控制，左上角可返回曲库换歌。
- 琴弦竖直排列。按住一根琴弦、向左右拉开后松手，可拨响单弦；按住鼠标，从左向右或从右向左连续划过多根弦，即可扫弦。
- 点击右上角齿轮打开“演奏设置”抽屉，可选择弹奏模式、拨片／指腹／闷音／泛音模拟，分别切换原声、合成伴奏与鼓点，调整音量和播放进度，并进入和弦校正。打开设置会暂停练习，完成后选择“回到琴弦”；`Esc` 也可关闭抽屉。
- 在琴弦区域点击鼠标右键可止音。
- 练习始终按歌曲原速播放，并完整显示旋律谱中的每个起音，不再稀释或筛掉节拍；原声、无人声伴奏和鼓点速度也不会改变。
- 可选键盘操作：`A`、`S`、`D`、`F`、`G`、`H` 从低到高独立拨六根弦，`J` / `K` 双向扫弦，`M` 止音，空格播放或暂停。编辑输入框时先完成输入，再使用快捷键。
- 加载曲目后，可以跟随节拍练习；发现和弦不合适时，在和弦校正界面调整和弦及其起止位置。

逐音提示会随播放进度平滑落向对应琴弦，显示目标品位和时值。命中后该音符立即从轨道消费，并只在对应琴弦的判定线留下短促反馈；漏击仍会越线淡出，界面不会为每个音重复弹出中央文字。旋律跟弹或旋律挑战中，累计判定至少 6 个音、节奏准确率达到 85% 后，播放期间会出现背景边缘光效。

演奏设置中的原声音轨、无人声伴奏和鼓点有独立开关，默认都关闭，此时只听见自己拨弦的声音。拨弦默认使用项目内置的 FluidR3 尼龙弦吉他采样；浏览器不能解码采样时会自动回退到本地物理建模音色。原声音轨播放导入文件或当前内置曲目的完整录音。两首内置曲目优先使用本地分离好的完整无人声轨；文件缺失或浏览器无法解码时，自动回退为根据分析结果在本机生成的近似伴奏。普通本地导入歌曲仍使用本机生成方案。

## 自动转录与开发校验

普通玩家入口只有 MP3 音频上传，不需要寻找或上传琴谱。完整处理均在浏览器本地完成：

- Web Audio API 负责解码音频，并将转录输入重采样到 44.1 kHz。
- OpenVPI GAME 1.0.3 small ONNX 是歌声主旋律转录的主模型。音频按 20 秒分块、4 秒重叠送入模型，并执行 8 步 D3PM 推理，直接识别音符边界、时值与音高。
- Basic Pitch 1.0.1 只补全超过 2.2 秒且没有 GAME 歌声音符的器乐前奏、间奏或其他空隙，不与歌声主结果混合抢音。
- 自定义浏览器 DSP 分析速度与拍点、调性、波形和和弦；逐音模型检测到的独立起音不会按固定间隔稀释。
- `onnxruntime-web` 与 TensorFlow.js WASM 分别在独立 Worker 中执行模型推理，避免长时间占用界面线程。

生成的逐音旋律、节拍、和弦与波形会随歌曲保存在 IndexedDB 中。分析结果带有 pipeline 版本；当前为 v6。打开旧版本导入的歌曲时，应用会读取 IndexedDB 中保存的原始 MP3 并重新分析，同时保留玩家已经校正过的节拍和和弦，不要求重新上传音频。

节拍估计会校正把八分音符误判成双倍 BPM 的情况，逐音识别范围也已扩展到吉他低音和高声部，并保留有明确起音证据的短音与连续同音重奏。

项目另有独立的 [MIDI / MusicXML 对照脚本](scripts/README-score-tools.md)，只供开发和测试自动转录准确性。它可以列出谱中的 part、voice 和 staff，从指定主旋律声部生成 oracle JSON，并与纯音频输出比较错音、八度错误、覆盖率和起音偏差。该脚本不属于玩家流程，页面也不提供琴谱导入入口。

开发时可用 [GAME ONNX 转录脚本](scripts/README-game-transcription.md) 从同一份音频重建内置逐音 JSON，并用 [MIDI / MusicXML 对照脚本](scripts/README-score-tools.md) 量化检查起音与音高。旧的 [人声旋律精修脚本](scripts/README-audio-melody.md) 仍保留用于历史结果复核，不属于玩家导入流程。

## 曲目与保存

当前本地实验内置 **See You Again — Wiz Khalifa feat. Charlie Puth**（约 3:50）和 **小美满 — 周深**（约 3:34）两首完整 MP3，首次打开或从旧版本升级时会在本机重新分析。文件信息见 [public/demo/SOURCES.md](public/demo/SOURCES.md)。这些音频仅供当前电脑上的个人实验，不应提交到公共仓库或对外分发。

在其他电脑上重建曲库时，请使用自己合法持有的普通音频文件并从曲库导入。可购买下载的正规入口包括 [Qobuz 的 See You Again](https://www.qobuz.com/us-en/album/see-you-again-feat-charlie-puth-wiz-khalifa/0075679927750) 和 [Qobuz 的《小美满》](https://www.qobuz.com/us-en/album/-/anirr279ll4pc)；购买与地区可用性以网站为准。本项目不会自动购买、抓取或解密受保护音频。

将本地 MP3 文件拖入页面，或使用导入按钮添加歌曲。应用在浏览器内转录逐音主旋律，并估算节拍和大、小三和弦；纯音频的自动结果仍可能受复音编曲、混响和弱人声影响，需要以测试琴谱持续回归验证，也不是原曲吉他六线谱。

歌曲标题、歌手和封面会自动读取文件内嵌标签，并在曲库中以完整正方形比例显示；缺少标签时，标题和歌手可从“歌手 - 歌名”形式的文件名推断。缺少内嵌封面时，应用会按标题与歌手匹配公开曲库的对应封面；同名匹配不明确、没有结果或网络不可用时使用默认唱片图。封面查询只发送标题和歌手文本，不发送音频文件。没有自定义封面上传功能，也不使用 AI 生成封面。

音频、封面信息、分析结果和校正记录保存在当前浏览器、当前地址的 IndexedDB 中。保持使用同一浏览器与 `http://127.0.0.1:5173`，刷新或重新打开后可继续使用；切换浏览器、端口或 `localhost` 地址会进入另一份存储。清除网站数据或使用隐私模式可能使保存内容丢失。

和弦校正页可导出分析 JSON，供开发排查或备份；重新生成一首歌时只需保留自己的原始音频文件。
